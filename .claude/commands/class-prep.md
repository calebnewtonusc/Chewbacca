# Class prep

For $ARGUMENTS, or every class meeting today if no course is given.

```bash
coursework today
coursework due --days 3
```

Then, from the course file in the ledger and any course materials on disk:

1. **What is due at this session**, including the recurring work the schedule
   does not date individually. Reading responses and pre-class posts are the
   ones that get missed.
2. **What the session covers**, from the weekly schedule, and the reading that
   goes with it.
3. **Three questions to walk in with.** Real ones, from the reading or from
   whatever was unclear last session. This is the difference between attending
   and being present.
4. **What to physically bring.** Laptop, sketchbook, lab notebook, printed
   draft. Courses that require a laptop for in-class writing say so once, in
   week one, and never again.

If office hours are today, say when and where.

Keep it under 200 words. This gets read walking to class.
