# Grades

```bash
coursework grade $ARGUMENTS
```

## Read the output honestly

- **`standing` is computed only on what is graded.** A standing built from 24% of
  the grade is a weak signal. Say which fraction is in.
- **`needed` above 100 means the target is gone.** Say that plainly rather than
  softening it. A target that cannot be hit is worth knowing in October, when
  there is still time to reallocate effort to a course where it can.
- **Contract-graded courses print no number**, and that is correct. There is no
  average to take. Count infractions against the step table instead: absences,
  late essays, late ancillary work, lapses, minus one step for each further
  revision completed. Check whether the eraser clause is still unused; it is
  worth a full step and people forget they have it.

## Then the useful sentence

Not the current number. What the next graded item does to it, and what the
cheapest available step up actually is. Often that is not studying harder: it is
a make-up attendance assignment, an ungraded revision, or a late ancillary item
that can still be turned in before the cycle closes.
