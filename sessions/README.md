# Sessions

One file per working day that produced something worth keeping. Not a
changelog: the commits are the changelog. These are the parts that do not
survive in a diff.

What each one holds: every link that came in, every design decision and the
words that drove it, what broke and how it was found, and the corrections that
cost the most. Quotes are kept verbatim, including the blunt ones, because the
exact wording is usually more precise than the paraphrase.

**If you just pulled, read the newest one.** It is the cheapest way to avoid
repeating a day somebody already paid for.

The lessons that generalise beyond one day get promoted out of here: into
`.claude/rules/`, into a skill, into `second-brain/memory/`, or into a hook
that refuses. A lesson that stays only in a session file was not learned.
