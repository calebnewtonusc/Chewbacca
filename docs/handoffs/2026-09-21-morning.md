# Where this stopped, 2026-09-21 morning

Caleb went to class mid-session. Everything below is committed and on main.

## Tune the portal, in one minute

Three knobs, live, no rebuild. Draw a circle, run a command, draw again.

```
portal reach 0.4    how far from centre your hand can push it
portal size  0.3    how big the ring is next to the circle you drew
portal gain  0.2    how much it follows your head
```

Current values are those. Say which numbers feel right and they become the
defaults. Run a bare `portal reach` to read one back.

**It can no longer go off screen.** The cursor is clamped and the centre is
inset by its own radius, so a wrong mapping is visible rather than silent.

## What is still open

**The strategy document he asked for and did not get.** He asked to
"strategize all the upgrades fixes and refactoring and research and creative
problem solving" and then to make it "a billion times better in EVERY way".
Four pieces of research came back and only live in the transcript:

- **Prompt cache ordering is worth 7% to 84% hit rate**, and the measured
  voice turn showed `cache_creation 57,888, cache_read 0`. Nothing has
  audited what sits in front of the stable prefix.
  ([ProjectDiscovery](https://projectdiscovery.io/blog/how-we-cut-llm-cost-with-prompt-caching))
- **Accuracy falls over 30% when the relevant text is in the middle** of a
  long context, and 5K of targeted retrieval beat a 100K summary on the same
  task. The voice agent loads about 53,700 tokens every turn.
  ([Sourcegraph](https://sourcegraph.com/blog/context-engineering))
- **Audit the query distribution before building graph retrieval.** The
  gains are real and concentrated in a query class that may be a sliver of
  traffic, and 72 to 80 percent of enterprise RAG never reaches production.
  `bin/corpus` can run that audit on his own 18,154 user turns.
  ([RAG vs GraphRAG](https://arxiv.org/html/2502.11371v3))
- **Routers cut 45 to 85 percent of cost**, and rule-based routing costs
  under a millisecond. The pleasantry fast path is the first instance.
  ([Routing and cascades](https://arxiv.org/html/2602.09902v1))

**The behavioural pass has still never run.** `fitness.jsonl` holds 12 rows
and **0** carry per-case results. The credit-assignment path built this
morning has never executed once, which is the same shape as everything else
that was built and never fired. `fitness --run` costs model calls and takes
a while; run it in the background.

**The voice cache miss.** 57,888 tokens created, 0 read, on the first turn
of a session. Worth one measurement before any theory.
